# 제조공정 개선 검토 랜딩페이지

중소 제조기업의 AI·데이터 기반 공정 개선 검토를 안내하는 정적 HTML 랜딩페이지입니다.

## 배포

저장소를 Vercel에 연결하면 별도 프레임워크나 빌드 과정 없이 배포할 수 있습니다.

- 진입 파일: `index.html`
- Vercel Framework Preset: `Other`
- Build Command: 비워 두기
- Output Directory: `.` (저장소 루트)

## 문의 폼 연결

현재 Google Form 주소가 비어 있어 페이지에 연결 안내가 표시됩니다. 문의 버튼을 실제 폼에 연결하려면 `index.html` 아래쪽 스크립트의 `GOOGLE_FORM_URL` 값에 Google Form 주소를 입력하세요.
